# NL Alert

A Home Assistant app combining Burgernet, AMBER and NL-Alert in one dark glass dashboard with an interactive OpenStreetMap map, clusters and alert areas.

Open the dashboard with **Open Web UI**. Install/start **Mosquitto broker** and configure the **MQTT integration** to automatically receive sensors. The app finds the MQTT service without manually entering credentials.

See **Documentation** for installation, configuration, sensor attributes and automation examples.
